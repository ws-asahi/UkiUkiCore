= UkiUkiCore 同梱版について =

このライブラリは https://github.com/arduino-libraries/Ethernet[arduino-libraries/Ethernet] v2.0.2 を
UkiUkiCore(AVR DU)向けに調整したものです。変更点は `src/utility/w5100.h` の2点のみで、API は公式版と同一です。

* SPI クロック要求を 14 MHz → 8 MHz に変更 (`ARDUINO_ARCH_MEGAAVR` のとき)。
  AVR DU の SPI 分周は /2, /4, /8 ... のため、24 MHz 動作では 14 MHz 要求が 12 MHz に丸められ、
  W5100 搭載シールドが応答しない(レジスタ読み値が1ビットずれる)ことを実機で確認済み。
  8 MHz 要求なら F_CPU = 12/16/20/24 MHz でそれぞれ 6/8/5/6 MHz となり、いずれも W5100 で動作する。
* チップセレクトの操作を PORT の OUTSET/OUTCLR レジスタによるアトミック書き込みに変更。

UkiUkiduino では CS = D10(W5100) / D4(SD カード) の標準的なシールド配線がそのまま使えます。
D13(SCK) は Serial2 の TX と共用のため、Ethernet/SD 使用中は Serial2 を開かないでください。
